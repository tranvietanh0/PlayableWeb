# Skill Domain Routing (theonekit-web)

Intent-based discovery for web kit skills. For core T1K skills (cook, fix, plan, etc.), see `skills/t1k-help/references/skill-domain-routing.md`.

## Frontend Development

User wants to...
- Build React components using modern patterns (hooks, suspense, server components) → `frontend-development`
- Style with Tailwind CSS or shadcn/ui components → `ui-styling`
- Replicate a design from a screenshot, video, or Figma mockup → `frontend-design`
- Apply React performance optimization patterns → `react-best-practices`
- Use TanStack ecosystem (Query, Router, Form, Table) → `tanstack`

## Backend Development

User wants to...
- Build REST, GraphQL, or tRPC APIs → `backend-development`
- Add authentication (Better Auth, OAuth, sessions, magic links) → `better-auth`
- Design or query relational/document databases (Postgres, MongoDB, SQLite) → `databases`

## UI/UX Design

User wants to...
- Review UI for accessibility, contrast, spacing, and UX quality → `web-design-guidelines`
- Apply advanced UX/UI design patterns (50+ styles, micro-interactions) → `ui-ux-pro-max`
- Generate designs using AI (Stitch) → `stitch`
- Build brand identity and design systems → `design`

## Web Frameworks

User wants to...
- Build with Next.js App Router, RSC, Server Actions → `web-frameworks`

## Testing

User wants to...
- Write Playwright E2E, Vitest unit, or k6 load tests → `web-testing`

## DevOps & Deployment

User wants to...
- Deploy to Cloudflare, GCP, Kubernetes, or Docker → `devops`
- Quick deploy to any cloud platform → `deploy`

## Commerce & Payments

User wants to...
- Integrate payment processors (Stripe, Paddle, SePay, Polar) → `payment-integration`
- Build Shopify storefront apps, themes, or Liquid templates → `shopify`

## Content & Documentation

User wants to...
- Write high-conversion marketing or product copy → `copywriting`
- Build or customize a Mintlify documentation site → `mintlify`

## Notes

- All skills above are web-kit skills; invoke via the Skill tool
- For core T1K workflow skills (cook, fix, plan, test, review), see `skills/t1k-help/references/skill-domain-routing.md`
- Combine frontend + backend skills for full-stack features; see `skills/t1k-help/references/skill-workflow-routing.md` for chains
